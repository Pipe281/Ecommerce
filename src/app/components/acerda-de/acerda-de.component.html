🛒 Acerca de Ecommerce

Proyecto desarrollado para aprender Angular mediante el consumo de una API REST, navegación entre componentes y visualización de productos.

💻 Frontend

  • Angular 18
  • TypeScript
  • HTML5 y CSS3
  • Angular Router
  • HttpClient

🌐 Backend / API

  • Fake Store API
  • Servicios REST
  • Datos JSON

🛍️ Funcionalidades

  • Listado de productos.
  • Detalle de productos.
  • Navegación entre páginas.
  • Diseño responsive.

⚙️ Conceptos Aplicados

  • Standalone Components
  • Interfaces TypeScript
  • Inyección de Dependencias
  • Servicios Angular
  • Observables (RxJS)
  • Routing
  • @for y @if (Control Flow de Angular)

🎯 Objetivo

Comprender los fundamentos de Angular, el consumo de APIs REST y la construcción de aplicaciones SPA modernas.
